## 1. 產品概述

### 1.1 背景
目前個人漫畫收藏全部存放於 `G:\Comics`，依地區分為 `HK`、`Japan`、`TW`、`US` 四個資料夾，總數約 **18,900 本 PDF / EPUB**，另有部分 ZIP / RAR / 7Z / MOBI 壓縮檔。檔案數量龐大，僅靠檔案總管難以掌握「擁有哪些漫畫、作者是誰、出版到第幾集、看到哪裡」。

### 1.2 產品目標
建立一個**只在本機執行**的網頁應用程式，用於：

1. 自動掃描漫畫資料夾，建立完整書目清單（系列 → 集數）。
2. 以專業、易用的介面瀏覽、搜尋、篩選所有漫畫。
3. 管理書籍資料：書名、作者、出版社、狀態、標籤、評分、備註。
4. 記錄閱讀狀態與收藏。
5. **雙擊書籍即以 SumatraPDF 開啟**閱讀。
6. 透過 `.env` 設定檔輕鬆更改漫畫來源路徑（例如磁碟機代號變更）。
7. 一鍵 `start.bat` 啟動。

### 1.3 非目標（本版本不做）
- 不提供線上存取、多使用者或登入功能。
- 不內建閱讀器（統一交由 SumatraPDF）。
- 不移動、改名或刪除任何漫畫檔案（唯讀管理）。
- 不支援散裝圖片資料夾（JPG / PNG 資料夾）。
- 不提供多國語言。

## 2. 現況分析（`G:\Comics` 掃描結果）

| 分類資料夾 | 顯示名稱 | 系列資料夾數 | 主要格式 |
|---|---|---|---|
| `HK` | 香港 | 約 73 | PDF（~6,600）、EPUB（~1,300）、ZIP/RAR |
| `Japan` | 日本 | 約 261 | EPUB（~7,000）、PDF（~3,900）、RAR/ZIP/7Z/MOBI |
| `TW` | 台灣 | 少量 | EPUB |
| `US` | 美國 | 少量 | EPUB |

**資料夾結構：** `分類 \ 系列資料夾 \ 集數檔案`，例如：

```
G:\Comics\Japan\BLUE GIANT\[Kmoe][BLUEGIANT]卷01.epub
G:\Comics\HK\[港漫][皇朝傳奇][倫裕國][中漫版][22完]\...
```

**命名特徵：** 大量資料夾 / 檔名使用 `[ ]` 或 `【 】` 標記資訊，如 `[港漫][書名][作者][出版社][22完]`，可解析出書名、作者、出版社、集數與完結狀態。

## 4. 功能需求

### 4.1 掃描與同步（F-SCAN）
| 編號 | 需求 | 優先級 |
|---|---|---|
| F-SCAN-01 | 掃描 `.env` 中 `COMICS_ROOT` 指定之資料夾 | 必要 |
| F-SCAN-02 | 第一層資料夾 = 分類（依 `CATEGORY_MAP` 對應顯示名稱） | 必要 |
| F-SCAN-03 | 第二層資料夾 = 系列；更深層子資料夾內的檔案歸屬同一系列 | 必要 |
| F-SCAN-04 | 直接放在分類資料夾下的單一檔案，視為「單本系列」 | 必要 |
| F-SCAN-05 | 支援格式：`.pdf .epub .zip .cbz .rar .cbr .7z .mobi`（可於 `.env` 調整） | 必要 |
| F-SCAN-06 | 增量掃描：以「路徑 + 修改時間 + 檔案大小」判斷新增 / 變更 / 刪除 | 必要 |
| F-SCAN-07 | 已不存在的檔案標記為「遺失」，不直接刪除紀錄（保留使用者資料） | 必要 |
| F-SCAN-08 | 掃描於背景執行，介面顯示進度（已處理數 / 總數） | 必要 |
| F-SCAN-09 | 正確處理含 `[ ]`、全形符號、中日文字元之路徑 | 必要 |

### 4.2 檔名解析（F-PARSE）
| 編號 | 需求 | 優先級 |
|---|---|---|
| F-PARSE-01 | 解析 `[..]` / `【..】` 標記，推斷：類型（港漫等）、書名、作者、出版社、完結狀態 | 必要 |
| F-PARSE-02 | 解析集數：`卷01`、`第01卷`、`第01話`、`Vol.01`、`-01`、`01` 等 | 必要 |
| F-PARSE-03 | 偵測「完」、「完結」、「22完」→ 狀態 = 已完結，總集數 = 22 | 必要 |
| F-PARSE-04 | 去除常見來源標記（如 `[Kmoe]`、網站名稱）作為書名清理 | 建議 |
| F-PARSE-05 | EPUB 讀取內嵌 metadata（title / creator）作為補充 | 建議 |
| F-PARSE-06 | 無法解析時，以資料夾名稱為書名，其餘留空供手動填寫 | 必要 |

### 4.3 封面縮圖（F-COVER）
| 編號 | 需求 | 優先級 |
|---|---|---|
| F-COVER-01 | PDF：擷取第一頁（PyMuPDF） | 必要 |
| F-COVER-02 | EPUB：讀取 OPF 指定封面，否則取第一張圖片 | 必要 |
| F-COVER-03 | ZIP / CBZ / RAR / CBR / 7Z：依檔名排序取第一張圖片 | 必要 |
| F-COVER-04 | MOBI 及無法擷取者顯示預設封面（依分類配色） | 必要 |
| F-COVER-05 | 縮圖存放於 `data/covers/`（WebP，寬約 300px），背景逐步產生並快取 | 必要 |
| F-COVER-06 | 系列封面預設使用第一集封面，可手動改選其他集 | 建議 |

### 4.4 書庫瀏覽（F-LIB）
| 編號 | 需求 | 優先級 |
|---|---|---|
| F-LIB-01 | 側邊欄分類：全部 / 香港 / 日本 / 台灣 / 美國（含數量） | 必要 |
| F-LIB-02 | 系列顯示模式：封面牆（Grid）/ 清單（Table）切換 | 必要 |
| F-LIB-03 | 搜尋：書名、作者、出版社、標籤（即時搜尋，支援部分字詞） | 必要 |
| F-LIB-04 | 篩選：格式、完結狀態、閱讀狀態、收藏、標籤 | 必要 |
| F-LIB-05 | 排序：書名、作者、新增日期、集數、評分 | 必要 |
| F-LIB-06 | 大量資料下仍流暢：分頁或虛擬捲動 | 必要 |
| F-LIB-07 | 系列詳細頁：封面、資料、集數列表（集數、檔名、格式、大小、閱讀狀態） | 必要 |

### 4.5 開啟漫畫（F-OPEN）
| 編號 | 需求 | 優先級 |
|---|---|---|
| F-OPEN-01 | **雙擊集數**（或點擊「閱讀」按鈕）→ 後端以 SumatraPDF 開啟該檔案 | 必要 |
| F-OPEN-02 | SumatraPDF 路徑由 `.env` 的 `SUMATRA_PATH` 設定 | 必要 |
| F-OPEN-03 | 「在檔案總管中顯示」：開啟檔案所在資料夾並選取該檔 | 必要 |
| F-OPEN-04 | 開啟後自動將狀態設為「閱讀中」（若原為未讀）並記錄最後閱讀時間 | 建議 |
| F-OPEN-05 | 系列層級「繼續閱讀」：開啟第一本未讀 / 閱讀中的集數 | 建議 |
| F-OPEN-06 | 安全性：只允許開啟資料庫中、位於 `COMICS_ROOT` 內的檔案 | 必要 |

### 4.6 資料編輯（F-META）
| 編號 | 需求 | 優先級 |
|---|---|---|
| F-META-01 | 編輯系列：書名、原文書名、作者、出版社、完結狀態（連載中 / 已完結 / 停刊 / 未知）、總集數、標籤、評分（1–5 星）、簡介、備註 | 必要 |

| F-META-03 | 可「還原為自動解析值」 | 建議 |
| F-META-04 | 批次編輯：多選系列後一次設定標籤 / 狀態 / 分類 | 建議 |
| F-META-05 | 標籤管理：新增、改名、刪除、合併 | 建議 |

### 4.7 閱讀狀態與收藏（F-READ）
| 編號 | 需求 | 優先級 |
|---|---|---|
| F-READ-01 | 每集狀態：未讀 / 閱讀中 / 已讀 | 必要 |
| F-READ-02 | 系列狀態自動彙總（例：已讀 12 / 22），也可一鍵全部標記 | 必要 |
| F-READ-03 | 收藏（星號）於系列層級 | 必要 |
| F-READ-04 | 「最近閱讀」清單 | 建議 |

### 4.8 統計儀表板（F-DASH）
| 編號 | 需求 | 優先級 |
|---|---|---|
| F-DASH-01 | 總覽卡片：系列數、檔案數、總容量、已讀比例 | 必要 |
| F-DASH-02 | 各分類系列數 / 檔案數 / 容量 | 必要 |
| F-DASH-03 | 格式分佈（PDF / EPUB / 壓縮檔…） | 必要 |
| F-DASH-04 | 最近新增、最近閱讀 | 必要 |
| F-DASH-05 | 閱讀進度（未讀 / 閱讀中 / 已讀 比例） | 建議 |
| F-DASH-06 | 資料品質提醒：缺作者、遺失檔案、封面失敗數量 | 建議 |

### 4.9 設定（F-SET）
| 編號 | 需求 | 優先級 |
|---|---|---|
| F-SET-01 | 設定頁顯示目前 `.env` 設定值（唯讀）及路徑是否有效 | 必要 |
| F-SET-02 | 「重新掃描」、「重建封面」按鈕與掃描紀錄 | 必要 |
| F-SET-03 | 匯出書目為 CSV / Excel | 建議 |

## 5. 設定檔（`.env`）

專案根目錄提供 `.env`（及範本 `.env.example`）。更換磁碟機時只需修改 `COMICS_ROOT`，再重新掃描即可；**已編輯的資料以相對路徑對應，不會遺失**。

```ini
# 漫畫來源資料夾
COMICS_ROOT=G:\Comics

# SumatraPDF 執行檔路徑
SUMATRA_PATH=C:\Users\<使用者>\AppData\Local\SumatraPDF\SumatraPDF.exe

# 網頁伺服器埠號（僅本機 127.0.0.1）
PORT=8000

# 分類：資料夾名稱:顯示名稱（依此順序顯示）
CATEGORY_MAP=HK:香港,Japan:日本,TW:台灣,US:美國

# 納入管理的副檔名
FILE_TYPES=pdf,epub,zip,cbz,rar,cbr,7z,mobi

# 啟動時是否自動增量掃描
SCAN_ON_STARTUP=true
```

> 說明：資料庫中檔案以「相對於 `COMICS_ROOT` 的路徑」儲存，因此搬移整個漫畫資料夾到其他磁碟後，閱讀狀態、評分、標籤等資料全部保留。

## 6. 非功能需求

| 類別 | 需求 |
|---|---|
| 語言 | 全介面繁體中文，日期格式 `YYYY/MM/DD` |
| 部署 | 僅本機執行，伺服器綁定 `127.0.0.1`，不對外開放 |
| 效能 | 支援 ≥ 30,000 檔案；書庫頁載入 < 1 秒；首次完整掃描（不含封面）< 3 分鐘；增量掃描 < 30 秒 |
| 安全 | 系統對漫畫檔案**唯讀**；開啟檔案僅限資料庫中且位於 `COMICS_ROOT` 的路徑 |
| 可靠性 | 單一檔案損毀不影響整體掃描（記錄錯誤後略過） |
| 介面 | 專業、簡潔、一致的設計；支援淺色 / 深色模式；適配 1366px 以上螢幕 |
| 易用性 | 一鍵 `start.bat` 啟動；無需資料庫安裝 |
| 資料備份 | 資料庫為單一檔案 `data/library.db`，可直接複製備份 |

## 10. 介面設計

### 10.1 設計原則
- 風格：專業、沉穩的「數位圖書館」感，封面為視覺主角，介面元素低調。
- 版面：左側固定導覽列 + 頂部搜尋列 + 主內容區。
- 一致的元件（shadcn/ui）、清楚的資訊層級、鍵盤可操作（`/` 聚焦搜尋、`Enter` 開啟）。
- 淺色 / 深色模式；四個分類各有識別色。

### 10.2 頁面清單
1. **儀表板**（首頁）
2. **書庫**（系列封面牆 / 清單）
3. **系列詳細**
4. **編輯資料**（對話框 / 側邊抽屜）
5. **標籤管理**
6. **設定與掃描**

## 11. 一鍵啟動（`start.bat`）

雙擊 `start.bat` 時自動執行：

1. 檢查 Python 與 Node.js 是否已安裝（未安裝則以中文提示）。
2. 若不存在 `.env`，自動由 `.env.example` 複製。
3. 首次執行：建立 Python 虛擬環境（`.venv`）並安裝套件。
4. 首次執行或前端有更新：安裝前端套件並編譯（`npm install && npm run build`）。
5. 啟動 FastAPI 伺服器（`127.0.0.1:PORT`）。
6. 自動開啟瀏覽器至 `http://127.0.0.1:8000`。
7. 關閉命令視窗即停止服務。

## 13. 驗收標準

1. 雙擊 `start.bat` 後，瀏覽器自動開啟系統首頁，全中文介面。
2. 首次掃描後，四個分類的系列數與檔案數與 `G:\Comics` 實際內容相符（誤差僅限不支援格式）。
3. 搜尋「BLUE GIANT」可於 1 秒內找到，並顯示正確封面與 10 集以上集數。
4. 雙擊任一集，SumatraPDF 正確開啟該檔（包含檔名含 `[ ]`、中文之情況）。
5. 修改系列作者後重新掃描，修改值保留不變。
6. 將 `.env` 的 `COMICS_ROOT` 改為其他路徑（例如複製到 `H:\Comics`），重新掃描後閱讀狀態、評分、標籤完整保留。
7. 儀表板數字與書庫一致。
8. 整個過程中 `G:\Comics` 內的檔案未被修改。
